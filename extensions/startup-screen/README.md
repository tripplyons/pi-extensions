# Startup screen

Replaces Pi's built-in header with a theme-colored `PI` wordmark and the current directory. Pi still renders its native Context, Skills, and Extensions lists. The extension removes the Prompts and custom Themes lists from the startup screen. Prompt templates remain loaded and usable.

The resource-section filter is adapted from Benjamin Davis's MIT-licensed [my-pi-setup](https://github.com/davis7dotsh/my-pi-setup/tree/main/extensions/ui-customization). See `LICENSE`.

This extension only changes TUI mode. It does not replace the footer, editor, or active theme.
