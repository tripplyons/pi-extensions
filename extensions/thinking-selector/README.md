# Thinking selector

Ctrl+T opens the reasoning effort picker instead of toggling thinking blocks.
The popup starts on the current level and lists only levels supported by the
selected model. Use arrow keys or j/k to move, Enter to select, and Escape to
cancel. Models without reasoning support show a warning.

Restored from the original thinking-selector extension. Supported levels come
from Pi's model API. Changes use Pi's session API, so resumed sessions retain
the selected effort without changing the default for new sessions.
